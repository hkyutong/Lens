# Lens 项目开发文档

## 项目概述

Lens 是 YutoAI 旗下的学术研究产品，面向老师、学生和研究人员提供论文阅读、学术写作、研究资料处理与多能力工作流。用户前端使用独立的 Vue/Vite 学术工作台，后端复用现有 99AI/NestJS 认证、会话、文件、计费、订单、分享和模型契约，学术任务由独立 FastAPI 进程执行。

## 核心模块

### 1. Lens 学术研究前端（chat）

- **技术栈：** Vue 3 + Vite
- **本地地址：** `http://127.0.0.1:9002`
- **功能特性：**
  - Lens 账号登录与新建研究会话
  - 论文、PDF、Word 和 LaTeX 资料处理
  - 普通研究问答、基础学术能力和函数插件
  - 流式研究结果展示
- **界面范式：** 采用 gpt_academic/Gradio 式研究布局，研究记录为主区，研究输入和学术工具集中在独立操作区。
- **边界：** 不提供 99AI 应用市场、旧聊天页面或通用聊天壳。

### 2. 管理后台（admin）

- **技术栈：** [Fantastic Admin Basic](https://github.com/fantastic-admin/basic)
- **功能特性：**
  - 多级管理员权限控制
  - 积分系统管理
  - AI 模型配置
  - 用户管理与数据分析

### 3. 99AI/NestJS 后端能力层（service）

- **技术栈：** NestJS
- **服务地址：** `http://localhost:9520`
- **功能特性：**
  - 认证、会话、文件、计费、订单、分享与模型接口
  - 学术服务鉴权、额度校验和代理转发
  - 数据库与缓存访问

### 4. 学术能力执行层（academic-4.0/main.py）

- **技术栈：** Python + FastAPI
- **默认端口：** `http://127.0.0.1:38000`
- **配置说明：** 参考 `docs/ACADEMIC.md`

## 本地启动

先确保 NestJS `9520` 和学术执行 API `38000` 已运行，再启动 Vue 前端：

```bash
cd chat
npm run dev -- --host 127.0.0.1 --port 9002
```

Vue 前端通过开发代理连接 `http://127.0.0.1:9520/api`；NestJS 再按既有契约调用 `38000` 的学术执行 API。Uvicorn 不生成或承载 Lens 用户页面。

## 开发指南

### 项目构建

项目提供了便捷的一键构建脚本：

```bash
./build.sh
```

执行后，脚本将自动完成所有模块的构建，构建产物将保存在项目根目录的对应文件夹中。

### 开发建议

1. 遵循项目既定的代码规范和提交规范
2. 确保新功能有完整的测试覆盖
3. 提交代码前进行本地测试
4. 及时更新文档

## 问题反馈

项目状态、长期规则和已确认变更分别记录在根目录 `STATUS.md`、`AGENTS.md` 与 `CHANGELOG.md`。提交问题或改动前先核对三件套，避免重新引入已经废弃的 99AI 用户端实现。
